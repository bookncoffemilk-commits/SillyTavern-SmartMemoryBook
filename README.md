# 📖 Smart Memory Book for SillyTavern

Интеллектуальный внешний модуль автоматической архивации ролевой сессии для **SillyTavern**.

Обычные модули саммари часто смешивают хронологию в одну кучу текста или начинают отыгрывать роль персонажа. **Smart Memory Book** выступает в роли холодного, изолированного **ИИ-Архивариуса базы данных**, который ведет структурированную летопись ролевой игры и может незаметно инжектировать эти знания обратно в мысли персонажей ("супер-память").

---

## ✨ Ключевые возможности

* 📜 **Три независимых раздела знаний:**
  * **Хроника сюжета (Plot):** Сжатая выжимка ключевых поворотов, текущих арок и целей.
  * **Детали о {{user}} (Player):** Статус, экипировка, физическое/ментальное состояние, раскрытые секреты и отношение к игроку.
  * **Мир & Окружение (World):** Локации, правила сеттинга, долги, обещания и статус второстепенных NPC.
* 🤖 **Полная изоляция от отыгрыша (Архивариус):**
  * Запрос на обновление выполняется «тихо» (в фоне) и отправляет модели **только** сырой лог реплик и текущие записи книги.
  * Модель возвращает структурированный `JSON` без приветствий, рассуждений и отсебятины.
* ⚡ **Гибкая настройка модели:**
  * Возможность использовать текущую модель чата либо подключить отдельный API (OpenAI, OpenRouter, локальный Ollama/LM Studio) со своим ключом и кастомным системным промптом.
* 🧠 **«Супер-память» (Инъекция в контекст):**
  * Персонаж всегда видит актуальные факты из трёх разделов перед генерацией ответа, даже если события произошли сотни сообщений назад.
* 🎨 **Dual-Tone Dark Mode (4 темы):**
  * 🌸 **Сакура:** черно-сливовая база с нежно-розовыми и оливковыми акцентами.
  * 🌲 **Лес:** лесная темная зелень с акцентами мха и ягод.
  * 🍂 **Осень:** теплый графит с янтарными и оливковыми тонами.
  * 💜 **Лаванда:** глубокий чернильный фон с лавандой и ночным синим.
* 🔘 **Умная плавающая кнопка (FAB):**
  * Дизайн 1-в-1 с интерфейсом Cozy Companion / Tavern Refined.
  * Свободно перетаскивается мышкой, не падает за границы экрана и автоматически примагничивается к соседним кнопкам.

## 📥 Установка в SillyTavern

### Способ 1: Установка по ссылке (Рекомендуется)
1. В SillyTavern откройте меню **Расширения** (иконка кубиков/пазла вверху).
2. Нажмите **"Install Extension"** (Установить расширение).
3. Вставьте ссылку на ваш GitHub-репозиторий:
   ```text
   https://github.com/ВАШ_НИК/SillyTavern-SmartMemoryBook
   ```
4. Нажмите **Install** и обновите страницу (`F5`).

### Способ 2: Ручная установка через Git
Перейдите в папку сторонних расширений SillyTavern и клонируйте репозиторий:
```bash
cd SillyTavern/public/scripts/extensions/third-party
git clone https://github.com/ВАШ_НИК/SillyTavern-SmartMemoryBook memory-book
```

## 🛠️ Использование

1. Нажмите на иконку книги **📖** на экране (ее можно перетащить в любое удобное место).
2. Задайте интервал сообщений (по умолчанию — каждые 10 сообщений).
3. При необходимости раскройте вкладку `⚙️ Модель, провайдер и промпт`, чтобы указать отдельный API-ключ или настроить поведение Архивариуса под ваш сеттинг.
4. Включите чекбокс **«Инъекция в контекст»**, чтобы персонажи автоматически помнили всё зафиксированное в книге.
